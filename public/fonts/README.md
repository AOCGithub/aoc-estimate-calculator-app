# Interface fonts

Status: operational asset inventory
Reviewed: 25 November 2026

Inter is hosted with the application for interface use. The calculator also retains its configured IBM Plex Sans loading.

- `inter-latin.woff2`: Inter variable font, weights 400–700.
- `noto-sans/`: fonts embedded in generated payment/estimate PDFs.

Font license files are stored alongside the assets and copied into builds. Do not remove a license while its font remains distributed.

Source: <https://github.com/google/fonts/tree/main/ofl/inter>
