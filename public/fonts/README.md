# Interface fonts

Inter is hosted with the application for the entry page. The calculator retains its existing IBM Plex Sans stylesheet and font loading.

- `inter-latin.woff2`: Inter, normal variable weights 400–700.

Source: Google Fonts' public font service. The original SIL Open Font License files are included alongside the fonts and copied into both builds. Downloaded 3 November 2026.

- [Inter source and license](https://github.com/google/fonts/tree/main/ofl/inter)
