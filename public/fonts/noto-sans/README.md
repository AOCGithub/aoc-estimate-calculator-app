# Noto Sans PDF fonts

Status: operational asset inventory
Reviewed: 25 November 2026

Regular and bold Noto Sans files are embedded only when generating the local payment/estimate PDF so accented and non-ASCII text renders consistently. Document data is not sent to a third-party PDF service.
